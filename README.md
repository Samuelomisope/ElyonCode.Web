# ElyonCode Website

A React + Tailwind landing page for ElyonCode, built mobile-first with clear CTAs, trust messaging, services, portfolio, and contact details.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```

## Notes

- WhatsApp buttons link to `https://wa.me/2349056296658`.
- Tailwind styling is configured in `tailwind.config.js`.
- Main page content is in `src/App.jsx`.
